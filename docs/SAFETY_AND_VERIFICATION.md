# Project ArcoIris — Safety & Verification Protocols

This document establishes the safety invariants and pre-flash verification steps for all Project ArcoIris firmware builds.

---

## 1. Safety Invariants

### Invariant 1: Block 0 Must Never Be Modified
- **Block 0 (`a810_010200.bin`)** contains the H8S Sub-CPU firmware that manages power distribution, the physical on/off switch, battery handshake, and boot initialization.
- If Block 0 is altered or corrupted, the camera cannot power up or initiate card updates.
- Every patch generated by [`d300s_tool.py`](../d300s_tool.py) enforces a strict assertion that Block 0 CRC remains **`0xB506`** (`SHA-256: 5497cc40cec05194eb55ab7805de07d4188a916120851b0b1edc65d4c995af9c`) with **zero byte differences** from stock.

### Invariant 2: Stock Binary Preserved Read-Only
- Stock `D300S102.bin` (`MD5: 7f5503b795fc41c83a26e98d834d48ff`) is treated as immutable reference material.
- Build scripts read the input binary and emit a newly generated output binary with recomputed Block 1 CRC-16/XMODEM checksums.

### Invariant 3: Checksum Validation Before Flashing
Both Block 0 and Block 1 end with a 2-byte big-endian **CRC-16/XMODEM** checksum. The camera updater verifies each block's CRC before flashing.
Always verify the output binary with:
```bash
python3 d300s_tool.py info "FLASH/REFLASH B5/D300S102.bin"
```
Expected output for **Build B5: Native Manual**:
```text

md5    : 6549191abe995c2f2b9253b3fd55ab2a

header : 53377a1dd16b177f516c496a95c488f79325921dd520022a1b43cc2120f5ac00
```

## 2. Hardware Flashing Procedure

1. **Card Preparation**:
   - Format a standard CompactFlash (CF) or SD card in the camera.
2. **Copy Firmware**:
   - Copy `D300S102.bin` (from **Build B5: Native Manual**, MD5 `6549191abe995c2f2b9253b3fd55ab2a`) to the **root directory** of the card (e.g., `DCIM`'s parent folder: `/D300S102.bin`).
3. **Battery Safety**:
   - Ensure the EN-EL3e battery is at least **80% charged** (or use an EH-5a AC adapter).
4. **Initiate Update**:
   - Insert the card into the camera and power it **ON**.
   - Press `MENU` → navigate to `Setup Menu` (wrench icon) → `Firmware version`.
   - Select `Update` → `Yes` and press `OK`.
   - Do **NOT** turn off the camera or remove the battery/card until the update finishes (~2 minutes).
5. **Verify On-Camera**:
   - Turn the camera off and back on.
   - In `Menu → Shooting Menu → ISO sensitivity settings`, set **Auto ISO sensitivity control** to **OFF**.
   - Rotate the exposure mode dial to **`M` (Manual)** and engage **Live View (`Lv`)**.
   - Rotate the **Shutter Speed** dial (`1/25s` to `1/8000s`) and hold **ISO + command dial** to verify real-time exposure simulation and live 64-bin luminance histogram response.
   - Press the **`INFO`** button during Live View to cycle display overlays and show/hide the histogram.

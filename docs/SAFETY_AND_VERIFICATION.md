# Project ArcoIris — Safety & Verification Protocols

This document establishes the safety invariants and pre-flash verification steps for all firmware builds.

---

## 1. Safety Invariants

### Invariant 1: Block 0 Must Never Be Modified
- **Block 0 (`a810_010200.bin`)** contains the sub-CPU firmware that manages power distribution, the physical on/off switch, battery handshake, and boot ROM.
- If Block 0 is altered or corrupted, the camera cannot power up or initiate recovery mode.
- Every patch generated by `d300s_tool.py` verifies that Block 0 CRC remains exactly **`0xB506`** with **zero byte differences**.

### Invariant 2: Stock Binary Preserved Read-Only
- Stock `D300S102.bin` (MD5: `7f5503b795fc41c83a26e98d834d48ff`) is treated as immutable source material.
- Patch scripts take the stock image as input and output a newly generated binary, never modifying stock in place.

### Invariant 3: Checksum Validation Before Flashing
Both Block 0 and Block 1 contain internal CRC-16/XMODEM checksums. The camera bootloader will reject any firmware file where computed CRC does not match stored CRC.
Always verify with:
```bash
python3 scripts/d300s_tool.py info FLASH/BRANDING/D300S102.bin
```
Expected output:
```
block 0: a810_010200.bin  off=0x0000070 len=  524290 crc stored=0xB506 computed=0xB506 OK
block 1: b810_102_.bin    off=0x0080072 len= 7340032 crc stored=0x886B computed=0x886B OK
```

## 2. Hardware Flashing Procedure

1. **Card Preparation**:
   - Format a standard SD or CompactFlash card in the camera (or FAT32 / FAT16 on PC).
2. **Copy Firmware**:
   - Copy `D300S102.bin` (from Build B4) to the **root directory** of the card (e.g. `E:\D300S102.bin`).
3. **Battery Safety**:
   - Ensure camera battery is at least **80% charged** (or use the AC adapter EH-5a).
4. **Initiate Update**:
   - Insert card into camera.
   - Power ON -> Press `MENU` -> Navigate to `Setup Menu` (wrench icon) -> `Firmware version`.
   - Select `Update` and press `OK`.
   - Do **NOT** turn off the camera or remove the battery until the update completes (~2–3 minutes).
5. **Verify On-Camera**:
   - Power camera off and on.
   - Menu should show `"PROJECT ARCOIRIS"` under Custom Settings and `"Project ArcoIris"` in the version screen.
   - Engage Live View (`LV` dial mode + shutter press) and observe the real-time histogram in the bottom-left corner.
